# Centennial CDL School website

Website for Centennial Trucking's CDL (truck-driving) school in Lindon, UT. Built by Velocity Forge. This is a separate site from centennialtrucking.com.

## Status

Wireframe stage (v1, Nov 12, 2026). Nothing is built or deployed yet.

## What's here

| Path | What it is |
|---|---|
| `wireframe/index.html` | Wireframe v1: Home, Class A program and Request info pages, in one self-contained file. Photos are grey placeholders until the photographer shoots. |
| `docs/context.md` | What the client asked for, plus notes on the current centennialtrucking.com brand and tone, and open questions for the client. |
| `docs/research.md` | Research report: recommended build stack, design skills, competitor pricing, the scroll-video stress test, and SEO / AI-search plan. |
| `CLAUDE.md` | Project rules that Claude Code reads automatically when you open this folder. |

## How to view the wireframe

Open `wireframe/index.html` in a web browser (double-click it in Finder, or run `open wireframe/index.html` from this folder on a Mac). It needs an internet connection only for the Google web fonts.

## Planned build stack

Recommended (not final): Astro on Netlify. See section 2d of `docs/research.md`.
